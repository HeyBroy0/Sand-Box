# Repository agent entrypoint

Read [README.md](README.md) first. It is the short task router and defines the repository workflow.

Inspect the active target ref and relevant repository state before editing. Follow the README links and load only the instructions needed for the task; do not preload all of `core/`.

For any task that may change a core surface, start with the [Core documentation router](core/read-core-readme-first/core-readme.md), then follow its required and task-specific reading routes before planning or editing.

Preserve user data, keep changes on task branches, and validate before reporting completion.
