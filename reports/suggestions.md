# Review notes for the summary

## Changes implemented in `summary_revised.docx`

- **Missing data (dark yellow):** Replaced the vague reference to pattern-mixture models with a decision rule: classify missingness as MCAR/MAR/NMAR; use 20 chained-equation imputations for MCAR/MAR when missingness exceeds 10%, compare with complete-case results, and use pattern-mixture sensitivity analyses for NMAR. This follows the revised statistical summary and the statistical-design document.
- **Significance, multiplicity, and group tests (dark yellow):** Clarified the two-sided α = 0.05 threshold, restricted Benjamini–Hochberg FDR to predefined secondary/exploratory feature families, stated that prespecified primary endpoints are not FDR-adjusted, and tightened the ANOVA/Kruskal–Wallis statement. Post hoc contrasts are qualified as needed rather than implied for every comparison.
- **Aim 2 analysis methods (yellow-highlighted `(i)`):** Added the Aim 2A mixed-model structure (pool/donor and batch random intercepts; paired compartment-by-dose term; generalized mixed models for non-Gaussian outcomes), Aim 2B paired enzyme/control comparisons and the additivity contrast with 95% CIs plus a dose-trend test across at least four doses, and Aim 2C pre/post-plasma mixture-model comparisons with within-donor plasma controls. Added the rule that mediation uses only individual-donor confirmation data, not pooled discovery material, with bootstrap confidence intervals and sensitivity analysis for unmeasured confounding.
- **Aim 2 confirmation power (dark yellow):** Tightened the last clause to state that the 12-donor/group confirmation is powered using the preliminary paired uptake and caveolin-1 effects in Fig. 11C–D.
- **Aim 3 non-responder phrase (red):** Removed “as potential weight and burden controls.” Non-responders are an exploratory subgroup, not a control group; the subgroup can support an association despite limited weight/HbA1c response but cannot establish a weight-independent semaglutide effect.
- **Aim 3 remodeling/mediation sentence (dark yellow):** Clarified that the remodeling score uses standardized lipotoxic-minus-protective axes and described mediation as exploratory, with 5,000 bootstrap resamples and sensitivity analysis.

## Additional recommendations for the document

1. **Correct the opening sentence.** “Lipidomics and single-vesicle data will be normalized, Batch corrected and imputed” conflates normalization, batch correction, and missing-data handling. Prefer: “Lipidomic and single-vesicle data will be normalized and batch-corrected; missing data will be handled according to the prespecified missingness strategy.” Keep imputation conditional on the missingness plan rather than implying all data are imputed.
2. **Make the normality sentence grammatical and decision-focused.** It currently reads as a fragment. State that distributional assumptions will be assessed with Shapiro–Wilk tests and Q–Q plots, then specify that parametric or rank-based methods will be selected accordingly.
3. **Fix the Aim 1 mixture-model description.** The current phrase “Determine if the mixed model is supported under a single distribution” is internally inconsistent. It should say that one- and two-component Gaussian mixture models will be compared by BIC; if the two-component model is unsupported, analyses proceed using the continuous per-particle distribution.
4. **Separate the primary lipid endpoint from GM3.** The statistical design identifies total sialyl-GSL as the primary paired compartment-contrast endpoint, with GM3 examined separately. The current “sialyl-GSLs and GM3 as primary endpoints” could incorrectly imply co-primary status.
5. **Revisit the PCA rationale.** PCA can summarize major patterns and reduce dimensionality; it does not itself “simplify multicollinearity.” Specify that adiposome compartment/origin will be assessed as a source of variation and that principal components will be used for dimension reduction.
6. **Restore the full Aim 1 feature-retention rule if space permits.** The source statistical design prespecifies five criteria: persistence after metabolic-burden adjustment; stronger association with vascular than metabolic outcomes; discrimination among metabolically matched but vascularly discordant participants; no association with a prespecified nonvascular control outcome; and an effect on naïve arteriole function ex vivo. State that features failing criteria are reported as metabolic-burden-associated, not discarded.
7. **Clarify Aim 1 model hierarchy.** The detailed design describes penalized regression (elastic net, with lasso/ridge sensitivity analyses) as the primary multivariable method; random forest/gradient boosting are exploratory. The summary currently gives elastic-net and gradient-boosted models equal standing. Also distinguish nested cross-validation from the single held-out validation in Cohort B baseline data.
8. **Tighten the Aim 1 meaningful-difference wording.** Use “a difference of at least 10 percentage points,” not “≥10% points.” The lipidomics plan gives the rationale as approximately one-fifth of the observed 47.9% sialyl-GSL-rich fraction (Fig. 7B); keep this labeled as a prespecified meaningful difference, not an observed between-group effect.
9. **Keep Aim 2 experimental units explicit.** Discovery uses six independent, non-overlapping pools per group, each made from 5–8 donors; confirmatory endpoints use 12 individual donors per group. Do not let pooled discovery data support donor-level inference. The summary should retain batch as a random effect and the compartment × dose term.
10. **Describe Aim 2C interpretation conservatively.** A uniform rightward shift in the per-particle distribution after plasma exposure supports acquisition; an unchanged distribution is consistent with selection at release. This does not establish preferential release or differential clearance, which the proposal identifies as beyond the current application.
11. **Avoid causal language for Aim 3.** The phrase “to isolate for semaglutide effect” overstates what a single-arm baseline/follow-up cohort can establish. Prefer “to estimate associations with and without adjustment for weight, fat mass, and HbA1c.” The source design explicitly states that this adjustment does not prove a weight-independent drug effect.
12. **Standardize the non-responder definition.** Write “less than 5% weight loss and less than 0.5 percentage-point absolute HbA1c reduction.” Keep it exploratory and call it a subgroup, not a control arm.
13. **Add the Aim 3 functional co-endpoint if the summary can accommodate it.** The statistical design defines a functional co-endpoint comparing each participant’s six-month vesicles with their own baseline vesicles using the same Aim 2 assays, with arteriole source held constant. The current summary omits this.
14. **Fix small consistency issues.** Standardize “single-vesicle,” “batch-corrected,” “mixed-effects,” “Ad-adiposome,” and “Circ-adiposome”; use consistent en dashes for Ad–Circ; add a space before “Software” after the final power sentence; and write “Cav-1” consistently.
