# Document Creation and Editing

**Status:** Initial operational draft for review.

Place a document with the responsibility that will maintain it. Before writing, identify its purpose, audience, canonical owner, authority, and lifecycle.

Write for use at the point of need. State important assumptions and limitations, distinguish requirements from guidance, and link to shared authority rather than creating a competing copy. Follow useful local conventions; do not impose unnecessary metadata, templates, indexes, or hubs.

Keep operational sources, core-preserved copies, generated composites, navigation documents, and proposals visibly distinct. Split content only when separate tasks, audiences, owners, or lifecycles make independent documents more useful.

Check factual claims and links. Update only the routes affected by the change. Use the core preservation procedure when an externally owned source needs a protected historical record.
